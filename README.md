# 日记面板（journal-dashboard）

日记面板 + 模板库的 Obsidian 插件：看板式任务面板 + 一键搭建模板库 + 用模板创建笔记，所有路径与看板列可在设置中自定义。

## 功能

1. **日记面板**（ribbon 日历图标 / 命令「打开日记面板」）：
   - **任务看板**：读取日记文件夹下所有日记的任务，按标签分列（默认 今天/明天/本周/以后），支持勾选写回、拖拽换列、每列添加任务、一键打开 task-list-kanban 完整看板
   - **今日卡片**：今日日记、心情、未完成数，可直接新建今日日记
   - **本周入口** / **最近日记** / **收件箱速记**
2. **模板库一键搭建**（命令「一键搭建/恢复模板库」）：
   - 目录创建严格跟随设置：只确保设置中指定的路径存在（默认 日记/每日、日记/每周、日记/模板），不预设额外目录
   - 安装 6 个内嵌模板到模板目录（已存在则跳过，不覆盖你的修改）
   - 自动配置 Templater、核心插件「模板」与「日记」（默认仅填空缺项，可开启强制覆写）
3. **创建命令**：新建日记 / 新建周记（调用 Templater 渲染；模板与目标文件夹在设置中可改）

## 设置界面

- **基础路径**：日记/周记/收件箱/看板文件/模板目录/脚本目录/今日事标题
- **任务看板**：看板区块开关、已完成列默认收起、**看板列可增删**（名称/标签/颜色）、无标签任务默认列
- **面板卡片**：四块卡片开关、最近日记与收件箱条数
- **创建命令**：每条命令的名称、模板路径、目标文件夹、文件名策略
- **模板库**：首次启用自动搭建、强制覆写外部配置

## 依赖

需要已安装并启用 **Templater** 插件（模板引擎）。插件配置默认只在对应项为空时写入，不会覆盖你已有的设置。

## 修改模板

- 日常改模板：直接编辑模板目录下的文件（不会被插件覆盖）
- 改插件的"出厂默认"：编辑 `src/templates.ts` 后重新构建

## 开发与构建

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（监听文件变化）
npm run build      # 生产构建，生成 main.js
```

## 发布流程

1. 修改 `manifest.json` 中版本号，并更新 `versions.json`（或运行 `npm version patch` 配合 version-bump）
2. 推送 tag（如 `1.0.0`），GitHub Actions 自动构建并创建 Release
3. 在 `obsidianmd/obsidian-releases` 仓库提交 PR 加入 `community-plugins.json`
